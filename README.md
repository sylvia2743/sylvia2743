### OWE in Practice

**The problem:** A request in a chat does not always make it clear who has agreed to do it, or whether it is finished.

**The flow:** Create a task → choose yourself or a linked contact → add an optional deadline or reminder → track the task → mark it complete. Tasks assigned to someone else require their acceptance.

**Design decisions:**

- One “Add task” entry covers personal tasks and assignments, so users do not have to find separate starting points.
- Sending a task and accepting responsibility are separate steps.
- Repeated follow-up reminders require the recipient’s consent.

**Current status:** Available through a LINE-authenticated workspace, with ongoing iteration.

**Evidence:** The [public walkthrough](https://www.sylviamotor.com/bits-lab/originals/owe.html) includes screenshots dated November 11, 2026, showing a sample personal task being created, viewed, and completed. It also shows reminder settings and acceptance cards. This demonstrates the recorded workflow; it does not verify recurring reminder execution or end-to-end LINE notification delivery.
